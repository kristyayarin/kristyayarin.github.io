## Project Overview 

A real-time environment project focused on building a modular scene using physically based assets and procedural textures.  
The project explores environment layout, modular asset design, and real-time rendering workflows using Unreal Engine.

## Responsibilities

- Designed and built the environment layout in Unreal Engine.
- Created modular assets for flexible scene construction.
- Modeled environment assets in Maya and Houdini.
- Developed procedural materials using Substance Designer.
- Textured assets using Substance Painter.
- Assembled and rendered the final scene in Unreal Engine 4.

## Technical Details

- Developed a **modular asset system** to allow efficient scene building and reuse of assets.
- Created **procedural materials in Substance Designer** to generate flexible and scalable surface details.
- Applied **PBR texturing workflows in Substance Painter** for realistic materials.
- Combined **Maya and Houdini modeling workflows** for environment assets.
- Completed **layout, lighting, and rendering in Unreal Engine 4** for real-time visualization.
